# HydroScan Rotate
Crop-rotation decision support for Egyptian fields, built on the existing HydroScan project (preserved in `original_hydroscan/`).

**Honest scope:** HydroScan's model classifies vegetation density only (≈ NDVI thresholds); it does **not** detect irrigation or crops, and no accuracy is claimed. Rotation scores use transparent rules over qualitative crop knowledge (unverified) plus whatever real data is reachable. Without internet the climate falls back to a clearly labelled illustrative table and soil is "unavailable".

Quick start: see HANDOFF.md. Docs: PROJECT_AUDIT.md, IMPLEMENTATION_LOG.md, TEST_REPORT.md.
Not certified agricultural advice — confirm with an agricultural engineer and a soil test.
